# English Learning Bot
### This bot is designed as a personal dictionary and learning tool, similar to Quizlet. Users can upload words to their personal dictionary and practice them in a randomized order by providing translations.

## Features

Personal Dictionary – Users can add and manage their own vocabulary list.
Randomized Learning Mode – Words appear in a random order for efficient memorization.
Answer Validation – Users provide translations, and the bot checks their accuracy.
Retry & Translation Help – If the answer is incorrect, users can try again or view the correct translation.
